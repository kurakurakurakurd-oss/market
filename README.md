# pedros - سیستەمی پێشکەوتووی بەڕێوەبردنی مارکێت و کاشێر (POS)

سیستەمێکی تەواو و سەردەمی بۆ مارکێت و دووکانەکان: فرۆشتن، کاشێر (POS)، بارکۆد، داخلکردنی ئەشیا، کۆگا (چی ماوە و چی نەماوە)، و ڕاپۆرتی فرۆشتن و قازانج.

---

## 🚀 ڕێنمایی کارپێکردن لەسەر کۆمپیوتەر (Localhost)

ئەگەر دەتەوێت پڕۆژەکە لەسەر کۆمپیوتەری خۆت یان کۆمپیوتەری مارکێت کار پێبکەیت:

### ١. پێداویستییەکان:
- بەرنامەی [Node.js](https://nodejs.org) دابەزێنە (وەشانی 18 یان نوێتر).

### ٢. هەنگاوەکانی دەستپێکردن:
فۆڵدەری پڕۆژەکە بکەرەوە لە تێرمیناڵ (Terminal / CMD یان VS Code) و ئەم دوو فەرمانە بنووسە:

```bash
# بۆ دابەزاندنی هەموو پڕۆگرامە پێویستەکان
npm install

# بۆ کارپێکردنی پڕۆژەکە
npm run dev
```

پاشان لە وێبگەڕ (Chrome یان Edge) بڕۆ بۆ:
```
http://localhost:3000
```
سیستەمەکە ڕاستەوخۆ دەکرێتەوە و دەستبەکار دەبێت!

## 🌐 چۆن پڕۆژەکە لەسەر ئینتەرنێت هۆست (Host) بکەیت بۆ فرۆشتن یان بەکارهێنان؟

ئەم پڕۆژەیە بە ستانداردەکانی مۆدێرنی React + Vite + TailwindCSS دروستکراوە و دەتوانیت بەخۆڕایی لە چەندین شوێن هۆستی بکەیت:

### ڕێگای یەکەم: هۆستکردن لە Vercel (زۆر خێرا و ئاسان)
1. بڕۆ بۆ ماڵپەڕی [Vercel](https://vercel.com) و هەژمارێک (Account) دروست بکە.
2. فۆڵدەری پڕۆژەکە ببە سەر GitHub یان لە کۆنسۆڵی Vercel فەرمانی `npx vercel` لێبدە.
3. بە کەمتر لە یەک خولەک لینکێکی جیهانی (وەک `pedros-market.vercel.app`) پێت دەدات کە دەتوانیت دومەینی تایبەتی خۆشتی پێوە ببەستیت.

### ڕێگای دووەم: هۆستکردن لە Netlify
1. بڕۆ بۆ [Netlify](https://www.netlify.com).
2. لە تێرمیناڵ فەرمانی `npm run build` لێبدە. فۆڵدەرێک بە ناوی `dist` دروست دەبێت.
3. لە ناو Netlify تەنها فۆڵدەری `dist` ڕابکێشە و دایبنێ (Drag and Drop)، ڕاستەوخۆ دەبێتە ماڵپەڕێکی چالاک.

## 📱 چۆن بیکەیتە ئەپی مۆبایل و کۆمپیوتەر (Desktop / Mobile App)؟

### ١. کردنی بە ئەپ لەسەر وێندۆز یان مۆبایل بە بێ هیچ پرۆگرامێک (PWA / Chrome Web App):
- کاتێک پڕۆژەکە لەسەر براوسەر کراوەتەوە (Chrome یان Edge)، لە بەشی سەرەوە سێ خاڵەکە دابگرە:
- بڕۆ سەر **Install app** یان **Save and share -> Install pedros as app**.
- پڕۆگرامەکە ڕاستەوخۆ وەک ئەپێکی سەربەخۆ دەکەوێتە سەر Desktop و Taskbar بە بێ ئەوەی شریتی براوسەری پێوە بێت.

### ٢. ئەپی ڕاستەقینەی وێندۆز (.exe):
دەتوانیت [Electron.js](https://www.electronjs.org) یان [Tauri](https://tauri.app) بەکاربهێنیت تا فایلی Setup (.exe) دروست بکەیت بۆ ئەوەی مارکێتەکان بتوانن بە دبل کلیک دایبەزێنن.

## 💾 پاشەکەوتکردنی داتاکان (Database & Storage)
ئەم پڕۆژەیە بە شێوەیەکی خۆکارانە گشت داتای کۆگا، نرخی کڕین و فرۆشتن، لیستەکان، وەسڵەکان و فرۆشراوەکان لە ناو کۆمپیوتەر/براوسەری بەکارهێنەردا (LocalStorage) پاشەکەوت دەکات، بۆیە تەنانەت ئەگەر ئینتەرنێتیش ببڕێت داتاکان پارێزراون و لە دەست ناچن.
